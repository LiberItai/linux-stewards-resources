# Everyday IT essentials for small businesses

Plain-English, do-it-yourself checks for everyday Windows, Mac and mobile devices —
maintained by [Linux Stewards](https://www.linuxstewards.com), a UK-based
technology-services business. If you would rather have it done for you, small jobs
are genuinely welcome: [linuxstewards.com/services](https://www.linuxstewards.com/services).

## 1. Backups (the one that matters most)

- Follow the 3-2-1 rule: **3 copies**, on **2 different kinds of media**, with **1 kept off-site or in the cloud**.
- Automate backups — don't rely on remembering to run them.
- Test a restore at least once. An untested backup is a hope, not a backup.

## 2. Updates

- Keep the operating system and applications updated; enable automatic updates where available.
- Reboot after major updates — many fixes only take effect after a restart.

## 3. Passwords

- Use a unique password for each account; a password manager is the practical way to manage this.
- Longer beats complicated: aim for 12+ characters, or a passphrase of random words.

## 4. Two-factor authentication (2FA)

- Switch on 2FA first for email and anything holding money or customer data.
- Prefer an authenticator app over SMS where it is offered.

## 5. Email & phishing

- Pause before clicking links or opening attachments from unexpected senders.
- Check the sender's real address; when in doubt, reach them through a known channel.

## 6. Device basics

- Restart regularly — it clears a surprising number of everyday problems.
- Keep at least 10–15% of the disk free so the machine keeps running smoothly.
- Keep built-in protection switched on (Windows Security; macOS Gatekeeper and XProtect).
- Remove software you no longer use — fewer apps means fewer update and security chores.

## 7. Wi-Fi & router

- Change the router's default admin password.
- Use WPA2 or WPA3 with a strong Wi-Fi passphrase.
- Set up a guest network for visitors and non-work devices.

## 8. "Try this first" before calling for help

1. Restart the device.
2. Check it is updated.
3. Check cables, power, and whether Wi-Fi is connected.
4. Note the exact error message and what you were doing — this shortens any support call.

## When to get help

If a problem involves your data, money or customer records, or you are unsure, ask
rather than risk it. Entry fixes start from £12.
