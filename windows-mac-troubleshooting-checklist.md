# Windows & Mac troubleshooting checklist

A plain-English, step-by-step guide for small businesses and individuals when a
Windows PC or Mac is slow, freezing or misbehaving. Work through the steps in
order — each one is safe and reversible. If you reach the end without a fix, the
notes you have collected will make professional help much faster and cheaper.

## Before you change anything

- [ ] Restart the device. This clears most transient faults and is always the first step.
- [ ] Note exactly what changed recently — a new app, an update, a new printer, a cable, a move.
- [ ] Back up anything irreplaceable before attempting deeper fixes.
- [ ] Write down the exact error message, if any, word for word.

## Windows — slow, frozen or noisy fan

- [ ] Close apps and browser tabs you are not using.
- [ ] Open Task Manager (Ctrl+Shift+Esc) and look for a process using unusually high CPU, memory or disk.
- [ ] Check free disk space (Settings → System → Storage). Aim for at least 10–15% free.
- [ ] Run Windows Update and install pending updates, then restart.
- [ ] Run a quick scan: Settings → Privacy & security → Windows Security → Virus & threat protection.
- [ ] Reduce startup apps: Task Manager → Startup apps → disable what you do not need.

## Mac — slow, frozen or spinning beachball

- [ ] Quit apps you are not using (Cmd+Q, not just closing the window).
- [ ] Open Activity Monitor (Applications → Utilities) and look for a process using high CPU or memory.
- [ ] Check storage: Apple menu → System Settings → General → Storage, and clear large unused files.
- [ ] Run Software Update and install pending updates, then restart.
- [ ] Review Login Items: System Settings → General → Login Items, and remove what you do not need.

## Internet or Wi-Fi problems

- [ ] Restart the router and the device.
- [ ] Forget the Wi-Fi network and rejoin it, re-entering the password.
- [ ] Try the same device on another network (for example a phone hotspot) to narrow down where the fault is.
- [ ] Check whether other devices on the same network are affected.

## If it will not start

- [ ] Check power and cables; try a different outlet.
- [ ] Hold the power button for 10 seconds, then try starting again.
- [ ] Note any lights, sounds or on-screen text before it fails — these are useful clues.

## When to stop and get help

- [ ] Stop if a fix feels risky or if data is at stake — an unrecoverable mistake costs more than a repair.
- [ ] Summarise what changed, what you tried, and the exact error message.
