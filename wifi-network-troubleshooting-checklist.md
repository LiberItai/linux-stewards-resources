# Home & office Wi-Fi and network troubleshooting

Plain-English checks for a slow, dropping or dead home/office network — before you
spend on a call-out. This is a free guide from
[Linux Stewards](https://www.linuxstewards.com); if you would rather have it done
for you, we provide remote IT help worldwide.

## Start here (in order)

1. **Restart the obvious three, in order.** Power off the affected device, then the
   router, then the modem. Wait 30 seconds. Power the modem back on, wait for it to
   fully start, then the router, then the device.
2. **Check whether it is the Wi-Fi or the internet.** If one device is slow but
   others are fine, the problem is that device. If every device is slow, the problem
   is the router, the modem, or the line.
3. **Test with a cable.** Plug a laptop directly into the router with an Ethernet
   cable. If wired works and Wi-Fi does not, the fault is the Wi-Fi, not the line.

## Wi-Fi-specific checks

- Move closer to the router, or move the router to a central, raised, open position.
- Check for interference: microwaves, baby monitors, thick walls, mirrors, and
  neighbouring routers on the same channel.
- Switch between 2.4 GHz (longer range, slower) and 5 GHz (faster, shorter range).
- Forget and re-join the network on the affected device.
- Update the router firmware, then the device's Wi-Fi driver/OS.

## Internet / line checks

- Restart the modem and router (again, in the correct order).
- Check the router's status lights and admin page for a "no signal" or "down" state.
- Run a speed test while wired and compare it to the speed you pay for.
- Check for an outage with your internet provider before assuming your equipment is at fault.
- If you manage your own DNS, check it resolves; otherwise leave DNS on automatic.

## When to call for help

- Wired speed tests are consistently far below your plan even with one device connected.
- The connection drops several times a day after the checks above.
- You need a more reliable setup — a better router, a mesh system, or structured cabling.

## Keep it healthy

- Change the router admin password from its default.
- Keep the router firmware updated.
- Use a strong Wi-Fi password (WPA2/WPA3), not the default.
- Reboot the router monthly if it gets sluggish.
- Keep a written note of the network name and password somewhere safe.
