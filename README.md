# Linux Stewards — Free Technical Resources

Practical, no-nonsense checklists and references for Linux servers, small-business
IT and business automation — maintained by [Linux Stewards](https://www.linuxstewards.com),
a UK-based technology-services business.

Everything here is free to use. If you would rather have it done for you, Linux
Stewards provides remote help worldwide: [linuxstewards.com/services](https://www.linuxstewards.com/services).
