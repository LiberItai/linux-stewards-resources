# Should you automate that task? A 10-minute ROI checklist

A plain-English decision checklist for small-business owners deciding whether a
repetitive task is worth automating — before spending anything. Maintained by
[Linux Stewards](https://www.linuxstewards.com), a UK-based technology-services
business. If you would rather have the analysis or the automation done for you,
see [linuxstewards.com/services/business-automation](https://www.linuxstewards.com/services/business-automation).

Most automation projects fail to pay back not because the tools are bad, but
because the task was a bad candidate. Run a task through these ten questions
before you commit.

## The 10 questions

1. **Can you describe the task in one or two sentences?**
   If not, you do not understand it well enough to automate it yet. (Score 0)

2. **Is it repeated?** A task done once is not worth automating. Weekly or daily
   is. (0 or 2)

3. **Is it predictable?** The same steps each time, with clear inputs and
   outputs. Exceptions that need human judgement make it a poor candidate. (0/1/2)

4. **How much time does it actually take?** Estimate honestly — a task that
   "feels" big may be 10 minutes a week. (0/1/2)

5. **What does it cost in mistakes?** Copying, sorting and chasing by hand cause
   errors that cost money. If mistakes are expensive, automation gains value. (0/1/2)

6. **Is the data already structured?** Spreadsheets, forms and templates are easy
   to automate. Scanned paper and free text are harder. (0/1/2)

7. **Does it need a human decision?** Tasks that require judgement at the final
   step are fine — automation can draft, sort and remind, and a human approves. (0/1/2)

8. **Will the volume grow?** If the task scales with customers or orders, the
   saving grows too. (0/1/2)

9. **Can you verify the result?** You must be able to check the automation is
   working and correct. No way to verify = no way to trust. (0/1/2)

10. **Would you pay to stop doing it?** The simplest test: if you could hire this
    task away for a small fee, would you? If yes, automating it is the same
    decision. (0/1/2)

## Score it

- **0–7** — probably not worth automating now. Fix the process first.
- **8–13** — a candidate, but scope it narrowly: automate the smallest version first.
- **14+** — strong candidate. Automate it, keep a human in the loop, and measure the
  hours saved against the cost.

## The honest rule

Automation is worth it when the hours saved each week clearly exceed the one-off
cost of building and maintaining it. A £99 workflow that saves five minutes a
week is a bad deal; the same £99 workflow that saves three hours a week pays for
itself in a month.
