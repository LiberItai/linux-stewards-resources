# New computer setup checklist (Windows & Mac)

A plain-English, step-by-step guide for setting up a new Windows PC or Mac —
whether it is a first computer or a replacement for an old one. Work through the
steps in order; each one is safe and reversible. A few extra minutes here prevent
most slow-machine, "lost my files" and "got hacked" problems later.

## Before you start

- [ ] Keep the old device until you have confirmed every file you need is on the new one.
- [ ] Have your Wi-Fi name and password, and your email address and password, to hand.
- [ ] Have a USB drive or external hard disk ready if you are moving files manually.

## First hours — both platforms

- [ ] Connect to your Wi-Fi network.
- [ ] Run every operating-system update and restart when asked. Repeat until no updates remain.
- [ ] Turn on automatic updates so security fixes keep arriving on their own.
- [ ] Turn on full-disk encryption (Windows: Device encryption / BitLocker; Mac: FileVault).
- [ ] Set up a backup *now* (Windows: File History or OneDrive; Mac: Time Machine) and confirm the first backup completes.
- [ ] Set up a password manager or write strong, unique passwords down somewhere safe — never reuse one password across sites.
- [ ] Turn on two-factor authentication (2FA) for email and any banking or cloud accounts.
- [ ] Create a separate everyday account that is *not* an administrator, and use it for normal work.

## Windows

- [ ] Settings → Windows Update → install everything and restart.
- [ ] Settings → Privacy & security → Windows Security → confirm Virus & threat protection is on.
- [ ] Settings → Accounts → add your everyday (non-admin) account; keep the admin account for installing software only.
- [ ] Remove trial software you did not ask for (Settings → Apps → Installed apps → uninstall).
- [ ] Set your default browser and install an ad-blocking extension.

## Mac

- [ ] System Settings → General → Software Update → install everything and restart.
- [ ] System Settings → Privacy & Security → FileVault → turn on.
- [ ] System Settings → General → Time Machine → add a backup disk and complete the first backup.
- [ ] System Settings → Users & Groups → add your everyday (non-admin) account.
- [ ] Review System Settings → General → Login Items and remove anything you do not need to start automatically.

## Move your data

- [ ] Copy documents, photos and any business files from the old device or your cloud storage.
- [ ] Open a few of the copied files to confirm they are intact.
- [ ] Reinstall the applications you actually use, downloading only from official stores or vendor sites.
- [ ] Sign in to each app and confirm your data syncs.

## Before you call it done

- [ ] Confirm the first backup completed and you can see the files in it.
- [ ] Confirm the old device has everything copied off *before* you reset, sell or recycle it.
- [ ] Write down the new device name and your admin password somewhere secure.
